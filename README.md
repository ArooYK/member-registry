# Member Registry Contract

A contract that records and manages members of a community or protocol,
including membership status and role-based permissions.

## Key Functions
- `add-member` — Register a new member
- `remove-member` — Deregister an existing member
- `set-role` — Assign or update member roles
- `is-member` — Check if an address is an active member
- `get-member` — Retrieve member metadata and role info

Designed for DAOs, gated communities, governance systems, and permissioned apps.
